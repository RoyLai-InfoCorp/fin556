ONE-TIME SETUP08 / 19
03 / GIT · CONFIGURE GCMFIN556 / DAY 0

Connect WSL Git to GCM.

Example for a newer x64 installation:

$ git config --global credential.helper \
    "/mnt/c/Program\ Files/Git/ucrt64/bin/git-credential-manager.exe"

$ "/mnt/c/Program Files/Git/ucrt64/bin/git-credential-manager.exe" --version

Replace ucrt64 with the folder you found. Keep the escaping shown in the helper command.
