WEEKLY SETUP09 / 13
TROUBLESHOOTINGFIN556 / DAY 0

Container won’t start?

Check the basics

  • Docker Desktop is running.
  • Your internet connection is stable.
  • On Windows, WSL2 is installed and virtualization is enabled.
TRY AGAIN

Rebuild Container

Open the Command Palette and select Dev Containers: Rebuild Container.

If Docker will not start after installation, restart your computer.

WEEKLY SETUP10 / 13
TROUBLESHOOTINGFIN556 / DAY 0

Editor or Mac issues?

VS Code extensions

  • Select Developer: Reload Window.
  • Check that extensions are enabled.
  • Update VS Code if needed.

On macOS

  • Follow permission prompts in Privacy & Security.
  • For missing commands, check installation and PATH.
  • Use ARM64 apps on Apple Silicon.

For container file-permission issues, try rebuilding. If problems persist, search using the exact error message.
