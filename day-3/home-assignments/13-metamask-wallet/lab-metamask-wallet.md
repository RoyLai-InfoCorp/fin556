# MetaMask Wallet

💀⚠️ **IMPORTANT: NEVER USE YOUR REAL PRODUCTION WALLET KEY FOR LAB**

Before this lab, you should have completed "testnet" lab using a mnemonic generated by Hardhat and configured your hardhat network to use that mnemonic.

In this lab, you will create a new MetaMask wallet and configure your Hardhat network to use the same mnemonic as your MetaMask wallet. This way you can use your MetaMask wallet to interact with your testnet.

## 🛠️ Lab Practise: Create a new Metamask Wallet

### Step 1: Install Metamask and Create a new Wallet

💀⚠️ **IMPORTANT: WHEN RUNNING THIS LAB DO AVOID USING YOUR PERSONAL METAMASK WALLET BY MISTAKE.**

-   **Install Chrome Browser**

    To ensure maximum compatibility, we will use Chrome browser for this lab. If you don't have Chrome installed, please install it first (https://www.google.com/chrome/).

    NOTE: If you choose to use a different browser the screenshots and instructions may differ slightly. Please ensure that the browser is compatible with Metamask and you know how to create a new profile in that browser.

-   **Create a new profile in Chrome Browser**

    To avoid using your personal Metamask wallet by mistake, we will create a new profile in Chrome browser and use that profile for this lab.
    Follow the instructions here to create a new profile in Chrome browser: https://support.google.com/chrome/answer/2364824?hl=en

    The screen may look similar to the one below but may differ slightly due to updates in the Chrome interface. When in doubt, follow the instructions in the link above.

    ![chrome-profile](./img/chrome-profile.png)

-   **Download and Install Metamask Plugin**

    💀⚠️ **IMPORTANT: NEVER USE YOUR REAL PRODUCTION WALLET KEY FOR LAB**

    After logging in with the new profile, follow the instructions [here](https://metamask.io/download/). Click on "Get Metamask" and follow the instructions to install the Metamask extension for Chrome.

    ![get-metamask](./img/get-metamask.png)

-   **Running Metamask for the first time**

    After installing the extension, you will be asked to either import an existing wallet or create a new wallet.

    You will import an existing wallet in this lab using the mnemonic generated from the Test Wallet.

    ![metamask-firsttime](./img/metamask-firstime.png)

-   **Click "Import using Secret Recovery Phrase"**

    ![import-mnemonic](./img/import-mnemonic.png)

-   **Enter the mnemonic**

    Enter the following mnemonic (12 words) generated for your Test Wallet from the previous lab.

    ![enter-mnemonic](./img/enter-mnemonic.png)

-   **Enter Password for Metamask Wallet**

    You will be asked to enter a password for your wallet. **Enter a password you can remember otherwise you have to uninstall and reinstall Metamask again.**

-   **Done**

### Step 2: Connect Metamask to Testnet

-   **Select "Networks" from your Metamask Menu dropdown.**

    ![select-networks](./img/select-networks.png)

-   **Click "+Add a custom network"**

    ![add-testnet](./img/add-testnet.png)

-   **Enter the following information:**

    -   Network name = "Ethereum Hoodi"
    -   Default RPC URL = enter the Alchemy Hoodi testnet URL you created in the previous lab.
    -   Chain ID = 560048
    -   Currency Symbol = "ETH"
    -   Block Explorer URL = "https://hoodi.etherscan.io"

    ![enter-network](./img/enter-network.png)

-   **Click "Save"**

-   **Once you are connected, you should see `xxx ETH` in the wallet from your previous lab.**

    ![testnet-account](./img/testnet-account.png)

### Step 3: [Optional] Connect Metamask to Hardhat Standalone Network

You can connect Metamask to your local Hardhat network.

-   **Start hardhat node**

    ```bash
    hh node
    ```

-   **Add Network**

    Repeat the steps above to add a custom network in Metamask but use the following information instead.

    -   Network name = "Hardhat"
    -   Default RPC URL = "http://localhost:8545"
    -   Chain ID = 31337
    -   Currency Symbol = "ETH"

-   **Once you are connected, you should see `10000 ETH` in the wallet from your hardhat node.**
